# Play store screenshots (Whisperio for Android)

Generated by the `app-screenshots` skill kit from the Roborazzi baselines in `android/app/src/test/snapshots/`
(no device needed). Re-run after `:app:recordRoborazziDebug` changes the UI:

```sh
K=~/.claude/skills/app-screenshots
cd android/marketing/play/screenshots
node $K/tools/kit/kit.mjs all --shots shots.json          # raw/ + out/ + screenshots.config.json
node $K/tools/verify.mjs --config screenshots.config.json # gate: size 1080x1920 / 1024x500, no alpha, all langs
```

Output: `out/play-phone/{en,pl}/*.png` (4 phone shots, 9:16) and `out/play-feature/{en,pl}/feature.png` (1024x500).
`raw/` and `out/` are build output (gitignored); upload to Play Console only after Daniel approves the images.
